# 雕塑學系網站測試預覽

國立臺灣藝術大學雕塑學系網站靜態版的**測試預覽**，僅供內容檢查，非正式網站。

- 每頁設定不讓搜尋引擎收錄，並移除瀏覽統計
- 正式版本與轉換紀錄另存於私人儲存庫

## 網站架構與權限

### 對外網站：不用登入

- 對外網站只放公開資訊，任何人打開就能看，**不需要登入**。
- 網站上沒有會員、帳號、留言板或線上表單。老師和學生都**不需要、也沒辦法**在這裡登入。
- 要報名活動或填問卷時，頁面上的連結會帶你到學校或主辦單位現有的表單（例如 Google 表單、教務處招生網站），在那邊填寫。
- 網頁原始碼裡若看到 `wp-admin` 等字樣，是舊 WordPress 網站轉換時留下的程式設定，不是登入入口。

### 後台：只給系上工作人員

- 後台用來新增、修改網站內容，不對外開放。
- 必須在**校內網路**或透過**學校 VPN** 連線，再用**學校帳號**登入，才進得去。
- 後台有三種角色，都是系上工作人員：

  | 角色 | 可以做什麼 |
  | --- | --- |
  | 編輯 | 撰寫、修改內容 |
  | 審核 | 檢查內容，確認後才發布到對外網站 |
  | 管理 | 管理後台帳號與設定 |

- 老師或學生想更新網站上的資料（例如個人頁、活動消息），請聯絡系辦，由工作人員在後台處理。
